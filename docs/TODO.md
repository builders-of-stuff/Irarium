### Hotkey stuff

right now within an irarium, when writing/creating, if you press enter it adds a new node. This is okay, but sometimes a user may want to edit these settings. Like maybe instead of enter adding a new node it should be shift+enter or something else.

There should be a way to update these hotkeys, specifically how to add children nodes and sibling nodes, and if there's anymore special ones then do that too.

### Irarium & space cosmetics

Spaces are by default spherical/globe-like now. There should be ways to customize the look and style and colors and fonts of your spaces and irariums.

Probably locked behind a one-time upgrade or something.

Would also have to update the limitations with regards to coordinates an irarium can be published with within the space.

### Social stuff

Each irarium should have an option to allow others to edit or not.

And if enabled then other people can add nodes to your irarium, and they should be labeled/identified as such, perhaps add a new field to each node that indicates the author. This way others can build upon the same irarium, or add their thoughts and expand it too, collaboratively.

In addition, there should be a way for others to comment on the irarium as a whole, like per-irarium comment threads.
