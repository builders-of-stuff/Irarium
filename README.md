# Irarium

A space for thoughts

[Website](https://irarium.com/)

## Getting started

See [docs/SELF_HOSTING.md](docs/SELF_HOSTING.md) for instructions on how to run the project locally.

## How it works

Any user can create their own space.

Within a space, which can be public or private, shared or unshared, users can publish irariums within.

Irariums are like terrariums but for ideas, or just a space for thoughts.

An irarium can be structured, it can be messy, an ongoing dump of thoughts, or whatever you'd like it to be.

## Pricing

Every user gets 1 free space and can write and publish as many irariums within.

Buy additional spaces for about three fifty each.

Or expand spaces with space expanders, for a dollar each.

Ansibles are simply ways to "subscribe" to a space's feed. By default you see only irariums published within your own spaces, so unless you actively explore other public spaces others' irariums will not be visible to you.

Or you can just fork it and set it up for free yourself.
