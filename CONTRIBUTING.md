# Contributing to Irarium

Thank you for your interest in contributing to Irarium!

## Coding Standards

We follow a specific set of coding conventions to ensure consistency across the codebase.

**👉 [Read the Style Guide](docs/STYLE_GUIDE.md)**

Please ensure your code adheres to these guidelines before submitting a PR.

## Development Workflow

1.  **Setup**: Follow the "Getting Started" guide in [README.md](README.md).
2.  **Commands**: See [CLAUDE.md](CLAUDE.md) for a quick reference of common development commands.
3.  **Testing**: Run `pnpm run test` to ensure all tests pass.

## Pull Requests

-   Keep PRs focused on a single feature or fix.
-   Use descriptive titles and descriptions.
-   Reference any related issues.
